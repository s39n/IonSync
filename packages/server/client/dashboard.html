Danger Zone

Restore Deleted Files

Marks all files currently flagged as deleted on the server back to active. Use this if a sync accident caused files to disappear — your connected plugins will pull the restored files down on their next sync.

File content must still be present in server storage (within the 7-day retention window).

Remove All Conflicts

Deletes every file whose name contains "conflicted" from the server. This resolves all pending conflicts by discarding the conflict copies — the original files are kept untouched.

Conflict copies only. Original files are not affected.

Factory Reset

Permanently deletes all synced files, version history, and device records from the server. Connected plugins will be disconnected and must re-sync from scratch.

This cannot be undone.
